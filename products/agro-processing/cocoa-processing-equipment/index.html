Agro-Processing Equipment — Model BURGENTON CBL-500pro

Cocoa Butter Processing Line

Converting cleaned cocoa beans into cocoa liquor, cocoa butter and cocoa powder.

2-Year Warranty Genuine Spare Parts Technical Support Dealer Network Fast Delivery

The Burgenton Cocoa Butter Processing Line is a coordinated production system designed to convert cleaned cocoa beans into cocoa liquor, cocoa butter and cocoa powder. The configuration combines controlled alkalisation and roasting, bean winnowing, multi-stage grinding, insulated liquor handling, hydraulic butter pressing, cocoa-cake crushing, ultrafine milling, screening and dust-controlled packing.

Designed for growing African cocoa processors, cooperatives and food manufacturers seeking an integrated solution with mechanised material transfer, food-contact stainless-steel components and central electrical control. It can be adapted to workshop layout, desired product fineness, utility availability and packaging format.

Equipment Specifications

21 stations make up the standard CBL-500pro line, from raw-bean elevation through to dust-free powder packing.

01 Raw-Bean Elevator

Function / PurposeTransfers cocoa beans between processing stages. PVC buckets/belt; stainless-steel transmission/contact elements; carbon-steel frame.
Technical Specification0.75 kW reduction motor; approx. 4.0 × 0.7 × 0.5 m; 220 kg; 380 V / 50 Hz.
Configuration NoteConveyor length and discharge height are configured to the final workshop layout.

02 De-Stoning Machine

Function / PurposeSeparates stones and dense contaminants; supplied with fan, duct and cyclone-type dust collection.
Technical SpecificationMachine 1.1 kW; fan 3 kW; approx. 1.5 × 1.0 × 1.6 m; stated weight 320–380 kg; 380 V / 50 Hz.
Configuration NoteFinal quantity, interfaces and dimensions to be confirmed against the approved plant layout and process requirements.

03 Alkalisation Machine

Function / PurposeContinuous soaking/alkalisation belt with cleaning and vibratory drainage. Mesh belt, box body and pipework in 304 stainless steel; pump/motor carbon steel.
Technical SpecificationApprox. 3,100 × 850 × 1,400 mm; pump 2.2 kW; air pump 0.75 kW; vibration/drive 1.1 kW; 380 V / 50 Hz.

04 Process Elevators & Vibratory Hoppers

Function / PurposeVariable-speed transfer and quantitative discharge between treatment stages. PVC belt/cleats, stainless-steel hopper and carbon-steel frame.
Technical SpecificationElevator: 0.75 kW, approx. 0.6 × 0.6 m footprint, height matched to line. Hopper vibrator: 0.15 kW. 380 V / 50 Hz.
Configuration NoteConveyor length and discharge height are configured to the final workshop layout.

05 Continuous Belt Roaster/Dryer

Function / PurposeContinuous cocoa-bean roasting using frequency-controlled belt speed, dual temperature control and forced-air circulation.
Technical SpecificationApprox. 6.5 × 1.7 × 2.5 m; belt motor 0.75 kW; 5 × 3 kW circulating fans. Electric option: 90 kW heating. Gas option: stated 15–20 m³ consumption.
Configuration NoteChoose electric or gas heating after confirming local utility availability, roast profile and exhaust requirements.

06 Cooling Conveyor

Function / PurposeCools roasted beans using a variable-speed mesh belt and five forced-air fans. Stainless-steel belt/contact elements with carbon-steel frame.
Technical SpecificationApprox. 5.0 × 0.9 × 0.85 m; drive 1.1 kW; 5 × 0.55 kW fans; 380 V / 50 Hz.
Configuration NoteFinal dimensions to be confirmed against the approved plant layout and process requirements.

07 Cocoa Bean Peeling / Winnowing Machine

Function / PurposePeeling roller, vibrating screen, aspiration fan and gravity separation remove shells from roasted beans.
Technical SpecificationCapacity 500 kg/h; drive 0.75 kW; screen 0.18 kW; fan 1.5 kW; peeling rate >90–99%; approx. 1.4 × 0.7 × 2.4 m; 160 kg; 380 V.
Configuration NoteFinal dimensions to be confirmed against the approved plant layout and process requirements.

08 Inspection Conveyor

Function / PurposeVariable-speed belt for visual sorting and removal of defects/foreign material.
Technical SpecificationDrive 1.1 kW; approx. 5.0 × 0.9 × 0.85 m (length configurable); 380 V / 50 Hz.
Configuration NoteConveyor length and discharge height are configured to the final workshop layout.

09 Metal Detector

Function / PurposeDetects metallic contamination before grinding; audible/visual alarm with stop or reject function.
Technical Specification220 V; approx. 1,500 × 780 × 900 mm; 200 kg. Detection sensitivity/range to be confirmed through product testing.
Configuration NoteDetection sensitivity and reject arrangement must be confirmed through product testing.

10 Cocoa Liquor Grinding Set

Function / PurposeCombined rough and fine colloid milling converts cocoa nibs into cocoa liquor; fineness is adjustable.
Technical SpecificationTwo-stage 180/130 mill combination; 37 kW; processing fineness 2–100 µm; approx. 1.10 × 0.75 × 1.30 m.
Configuration NoteFinal dimensions to be confirmed against the approved plant layout and process requirements.

11 Water Chiller

Function / PurposeProvides cooling water for grinding mills and process tanks.
Technical Specification5 hp class; stated electrical power 5.5 kW; approx. 1.0 × 0.7 × 1.1 m.

12 Cocoa Liquor Receiving Tank

Function / PurposeReceives liquor after grinding and provides buffer capacity before transfer.
Technical Specification200 L; stainless steel; approx. 600 × 650 × 600 mm.

13 Insulated Paste Pumps

Function / PurposeHeated/insulated pumps transfer cocoa liquor and butter through the process.
Technical SpecificationFlow 5 m³/h; head 20 m; 3 kW; food-contact parts stainless steel, transmission parts carbon steel.

14 Liquor Mixing, Cooling & Storage Tank

Function / PurposeScraper-agitated tank cools, mixes and stores cocoa liquor before pressing.
Technical Specification1,000 L; inner and outer shell 3 mm; frame agitator 2.2 kW at 36 rpm; 380 V; approx. Ø1,300 × 1,800 mm.

15 Hydraulic Cocoa Butter Presses (2 Sets)

Function / PurposeHigh-pressure presses separate cocoa butter from cocoa solids/press cake.
Technical SpecificationModel BQYZ-460; 50 MPa unit working pressure; 210 t thrust; chamber Ø460 × 700 mm; stated feed capacity 150 kg/h each; heating 4 kW; motor 3 kW; 2,300 kg each.

16 Cocoa Butter Mixing & Storage Tank

Function / PurposeReceives, gently mixes and stores expressed cocoa butter prior to downstream filling or further processing.
Technical Specification1,000 L; inner and outer shell 3 mm; frame agitator 2.2 kW at 36 rpm; 380 V; approx. Ø1,300 × 1,800 mm. External cooling source required if cooling is used.

17 Cocoa Cake Coarse Crusher

Function / PurposeBreaks press-cake chunks into coarse powder suitable for fine milling.
Technical SpecificationModel 400; 500–600 kg/h; 18.5/22 kW; approx. 600 kg; all-stainless-steel construction stated.

18 CR600 Ultrafine Grinding Line

Function / PurposeFine milling, classification, cyclone separation and dust collection produce cocoa powder.
Technical SpecificationMain motor 37 kW; classifier 4 kW; dust-removal fan 11 kW; adjustable 40–300 mesh; indicative 400–600 kg/h on reference materials; approx. 3,000 kg; stainless steel.

19 Ultrasonic Rotary Vibrating Screen

Function / PurposeFinal classification of cocoa powder before packing.
Technical Specification1-deck ultrasonic screen; 200-mesh sieve; 380 V / 50 Hz; stainless steel; stated Ø1,500 × 1,215 mm; approx. 200 kg.

20 Dust-Free Powder Packing Machine

Function / PurposeReceives screened cocoa powder for controlled, low-dust bag filling.
Technical SpecificationPacking range, accuracy, bag type, speed and installed power to be selected according to customer package format.

21 Piping, Hot-Water & Control Accessories

Function / PurposeConnects process vessels and supports heated product transfer and basic line control.
Technical SpecificationInsulated pipes, valves and joints; insulated hot-water tank and circulation pump; 3 electrical power-distribution boxes.
