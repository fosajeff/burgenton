Agro-Processing Equipment — Model BURGENTON CNL-500pro

Cashew Nut Processing Line

A semi-automatic production system that processes raw cashew nuts into graded, peeled and packaged kernels.

2-Year Warranty Genuine Spare Parts Technical Support Dealer Network Fast Delivery

The Burgenton Cashew Nut Processing Line (Model BURGENTON CNL-500pro) is a semi-automatic production system designed to process raw cashew nuts into graded, peeled and packaged kernels.

The line combines raw-nut grading, cooking, shelling, shell separation, kernel drying, humidification, peeling, kernel grading and vacuum packaging.
